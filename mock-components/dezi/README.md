# Mock Dezi

A flow double for [Dezi](https://www.dezi.nl), built for the GF Sandbox (`sandbox/DESIGN.md`).
**This is not a Dezi implementation and must not be treated as one.** It reproduces just enough of
the v0.7 flow to sign a synthetic practitioner in and hand out an attestation the Nuts node accepts.

## Deliberate deviations

- Userinfo returns a plain JSON envelope `{verklaring_id, verklaring}`. The published v0.7 response
  is an encrypted JWE; the acceptance environment was observed returning a signed JWS. This third
  shape is owned by the GF Sandbox client and consumed by nothing else.
- There is one fixed practitioner (`persona.go`) and no real authentication. Consent is a button.
- Nothing cryptographic is committed. Run `./sandbox/generate-demo-certs.sh` once; it writes the
  demo CA, the TLS certificate and the attestation signing key to the gitignored `sandbox/.certs/`.
  Without `DEZI_SIGNING_KEY_FILE` the signing key is generated in memory and changes on every
  restart, which invalidates attestations already issued.

## Why the TLS listener exists

The Nuts node verifies the attestation by fetching the JWK Set named in the token's `jku` header.
jwx rejects any `jku` that is not HTTPS and requires a `kid` in the protected header, so the JWK Set
must be served over TLS even locally. The certificate comes from a demo CA generated by
`sandbox/generate-demo-certs.sh`, and `config/nuts.yml` allowlists the URL.

## Run

    go run ./mock-components/dezi
    go test ./mock-components/dezi/...

Or, containerized alongside the rest of the demo:

    ./sandbox/generate-demo-certs.sh     # once, writes to the gitignored sandbox/.certs/
    docker compose --profile sandbox up

## Endpoints

| Endpoint | Reached by | Purpose |
| --- | --- | --- |
| `GET /authorize` | browser | consent screen |
| `POST /authorize` | browser | consent submit, redirects back with `code` |
| `POST /token` | sandbox backend | authorization code exchange, PKCE S256 |
| `GET /userinfo` | sandbox backend | bearer protected, returns the attestation |
| `GET /dezi/jwks.json` | Nuts node | JWK Set, must be reached over HTTPS |
